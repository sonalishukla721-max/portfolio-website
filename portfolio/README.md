# Sonali Shukla — Personal Portfolio

A clean, responsive personal portfolio website for Sonali Shukla, an aspiring full stack developer and B.Tech Computer Science student.

## Features

- Professional hero section with Sonali's supplied profile photo
- About, Skills, Projects, Contact, and Footer sections
- Sticky responsive navigation
- Mobile hamburger menu
- Dark/light mode toggle
- Smooth scrolling and active navigation state
- Client-side contact form validation
- Three project cards with clearly marked replaceable URL placeholders
- Accessible semantic HTML and image alt text

## Technologies used

- HTML5
- CSS3
- Vanilla JavaScript

No React, Bootstrap, Tailwind, or external UI framework is used.

## Run locally

Open the `portfolio` folder in VS Code, right-click `index.html`, and choose **Open with Live Server**. Alternatively, open `index.html` directly in a browser.

## Replace personal information

- Replace `YOUR_EMAIL@example.com` in `index.html` with your email.
- Replace `YOUR_GITHUB_URL` and `YOUR_LINKEDIN_URL` with your social profile URLs.
- Replace each `GitHub (replace URL)` and `Live Demo (replace URL)` target in the project cards with real URLs when available.
- Replace the three project titles, descriptions, and technology badges with your own project details.
- Keep `images/sonali-shukla-profile.jpe` if you want to use the supplied profile photo, or replace it with another personal image while keeping the same filename.

The form is intentionally frontend-only. It validates the fields and shows a confirmation message but does not send email without a backend or form service.
